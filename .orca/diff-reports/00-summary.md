# 原型 vs 前端：差异对照与落地计划（2026-11-19）

> 原型：`E:\zxdevelop\opendesign\8d699fa3-6b49-4dbf-b40b-29c55c1d6429`（纯 HTML mock，无后端/鉴权）
> 真实前端：`E:\zxdevelop\project1\frontend\src`（Vue 3 + v21.css）
> 分页明细：`dashboard-mental.md`、`diet-sport.md`、`record-tongue.md`、`chat-settings-shell.md`

## 0. 总体结论

真实前端的功能完整度**高于**原型（真实 OCR/舌诊/SSE/CRUD/管理员/预警/摄像头等），差距集中在：
1. 视觉节奏与信息层级（页头三段式、卡片形态、字号/留白）；
2. 少量交互形态（常驻快捷问题、OCR 核对、克数联动、平板对话布局）；
3. 3 处真实缺陷（舌诊证型键名、免责声明缺失、橙色光晕偏离设计 token）。

**不移植 mock**：localStorage、假 OCR/舌诊结果、写死步数、示例「更新于刚刚」。
**不回退真实能力**：各报告「前端有、原型没有」清单逐条保留。

## 1. 跨页共性问题

### P1
1. **免责声明缺失**：原型体检 `index.html:460`、舌诊 `:518`、聊天 `:555` 均有；真实仅 `HealthAnalysis.vue:90/106`、`MentalView.vue:100` 有，体检/舌诊/聊天三页无（ChatView `:280` 仅为快捷问题提示文案，非常驻 fineprint）。
2. **卡片视觉偏离 v21 token**：`HealthRecord.vue:847/1020/1024/1136/1211` 使用橙色光晕 `rgba(255,155,113,…)`，与 `v21.css:19` 蓝色 accent 及 `tokens.css:50`「阴影仅限弹层与下拉」冲突。
3. **响应式**：对话页 769–1024 仍为 280px+1fr 双栏（`v21.css:1343-1346`、`ChatView.vue:950-951`），原型 `styles.css:1436-1439` 在 1024 即单列；壳体存在 `layout.css:156-198` 与 `v21.css:3084-3357` 双套规则（68/72px、82/84vw、z-index 29/59）冲突。
4. **面板头三段式缺失**：体检/饮食/运动/心理多处只有 h2 + hint，缺原型 `micro + h2 + deck` 层级。
5. **选择性对齐**：真实页面为承载历史/趋势/管理而纵向堆叠，不照搬原型两栏；回退布局会挤压图表。

### P2

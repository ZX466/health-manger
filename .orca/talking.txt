## 统一口径（已裁决，不再分叉）

1. 睡眠只记每日 `sleep_hours`（0–16）；睡眠债 = 近 7 个有记录日 `Σ max(0, 8 − hours)`，覆盖 <4 天显示“数据不足”。
2. 心理打卡每人每天一条，同日重复提交 = 更新（全量覆盖，前端每次提交带全字段）。
3. 量表每类每天最多 3 次；PHQ-9 Q9>0 或总分 ≥20、GAD-7 ≥15 → `crisis_flag=true`；后端强制，前端不得隐藏资源。
4. 识餐/体检 OCR 只返回草稿，确认后才写库。
5. 流式对话：用户消息先落库；assistant 仅在 `done` 后落库；断开即中止、丢弃半截。
6. `persona_style` 仅 `humorous` | `clinical`，默认 `humorous`；高风险/危机强制严肃关怀。
7. 热线只读 `MENTAL_HOTLINE`、`CAMPUS_COUNSELING`，默认空，不得编造号码；紧急文案只写 120/110 + 学校心理咨询中心。
8. 零新增依赖；表结构变更白名单：`MentalRecord`、`ScaleAssessment`、`AIConfig.persona_style`；本轮追加例外：`async_tasks` 新增（ASYNC-1，已获批）、`health_articles`/`user_health_goals` 删除（DB-2b，已获批）。
9. `safety.level` 仅 `normal` | `elevated` | `high`。
10. `crisis_resources()` 返回 `list[dict[str, str]]`：`{name, phone?, description}`；禁止 `join(dict)`。
11. 测试固定 `uv run python -m pytest -q`；E2E 单跑 `make e2e` 或 `uv run python -m pytest -q tests/test_e2e_smoke.py`。
